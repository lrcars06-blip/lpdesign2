# LP Design — site

Dossier plat, sans étape de compilation.

- `index.html` : tout le site (styles, scripts et visuels des réalisations inclus)
- `lp-design-motion.mp4` et `lp-design-motion.webm` : la vidéo de la section « Comment on travaille » (deux formats, chaque navigateur prend celui qu'il lit)

## Mise en ligne

1. Déposer ces fichiers à la racine d'un dépôt GitHub.
2. Importer le dépôt sur Vercel (preset « Other », aucun build) ou activer GitHub Pages.

## À régler dans `index.html`, bloc `CONFIG`

- `phone`, `phoneDisplay`, `email` : vides = masqués
- `formEndpoint` : vide = le formulaire reste en mode démonstration et n'envoie rien
